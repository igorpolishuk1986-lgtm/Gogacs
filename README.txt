1. Создайте на github.com новый публичный репозиторий и загрузите сюда все 3 файла (scraper.py, index.html, папку .github).
2. В scraper.py впишите имена каналов в CHANNELS.
3. Settings -> Pages -> Source: Deploy from branch (main, root).
4. Actions -> update -> Run workflow (первый запуск вручную).
5. Откройте https://<ваш-логин>.github.io/<репозиторий>/ на телефоне, добавьте на экран «Домой».
